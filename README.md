# Malva journal club slides

Quarto/reveal.js slides for the Melbourne Integrative Genomics journal club on 8 October 2026.

## Render

```sh
quarto render slides.qmd
```

Open `slides.html`. The deck uses Quarto's bundled reveal.js resources and a local CSS file.

## Status

This is the first content draft. The reported examples are based on León-Periñán et al. (Nature, 2026). The three demonstration slides describe planned workflows; no live-query result or plot is claimed yet. Before presenting, verify access to the Malva API, select and test exact probes and datasets, save outputs with index version and filters, insert the resulting figures, and rehearse the demonstrations.
